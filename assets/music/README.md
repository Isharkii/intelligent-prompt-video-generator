# Music Assets

Drop royalty-free MP3 files here named exactly:

| File            | Mood      |
|-----------------|-----------|
| `hype.mp3`      | hype      |
| `cinematic.mp3` | cinematic |
| `lofi.mp3`      | lo-fi     |
| `emotional.mp3` | emotional |
| `corporate.mp3` | corporate |

Suggested source: https://pixabay.com/music

The pipeline will automatically detect and embed the matching track at 30% volume (20% when mixed with voiceover). If a file is missing the pipeline continues with no audio — nothing breaks.
